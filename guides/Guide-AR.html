دليل تشغيل منظومة الإدارة العامة للمبيعات والشؤون التجارية

وزارة الصناعة والمعادن · شركة البريقة لتسويق النفط — نسخة الخادم الداخلي

فكرة المنظومة باختصار: تُشغَّل المنظومة مرة واحدة على جهاز خادم داخل الشبكة. بعدها يفتحها جميع الموظفين من متصفح الإنترنت العادي (Chrome أو Edge) على أجهزتهم، كلٌّ باسم مستخدم وكلمة مرور خاصة به. البيانات محفوظة في مكان واحد على الخادم، وأي تعديل يظهر عند الجميع خلال ثوانٍ. لا تحتاج أجهزة الموظفين إلى تثبيت أي برنامج.

1. المتطلبات

  • جهاز يعمل باستمرار داخل الشبكة (خادم Windows أو Linux، أو حتى جهاز مكتبي مخصص).
  • برنامج Python الإصدار 3.8 أو أحدث. لا تحتاج المنظومة أي مكتبات إضافية.
    على Windows: نزّله من python.org وفعّل خيار Add Python to PATH أثناء التثبيت. على Linux يكون مثبتًا غالبًا.
  • لا يحتاج التشغيل إلى اتصال بالإنترنت. (إن توفّر الإنترنت تظهر الخطوط العربية بشكل أجمل فقط.)

2. التشغيل لأول مرة

  1. فكّ ضغط الملف في مجلد ثابت على الخادم، مثل C:\ContractsSystem أو /opt/contracts-system.
  2. شغّل المنظومة:
    • على Windows: انقر نقرًا مزدوجًا على Start-Windows.bat.
    • على Linux: ./start-linux.sh
  3. في أول تشغيل ستظهر رسالة فيها كلمة مرور المدير (اسم المستخدم admin)، وتُحفظ أيضًا في الملف data/كلمة-مرور-المدير-الأولية.txt.
  4. تظهر أيضًا عناوين الوصول، مثل: http://192.168.1.20:8080. هذا هو الرابط الذي يفتحه الموظفون.
  5. افتح الرابط وادخل بحساب المدير، ثم غيّر كلمة المرور من صفحة «الإعدادات والاستيراد» ← «حسابي»، واحذف ملف كلمة المرور الأولية.
تأتي المنظومة محمّلة مسبقًا بكل البيانات: 39 عقدًا من سجل عقود البريقة، و393 منشأة من كشوفات الوزارة في 5 دفعات.

السماح للأجهزة الأخرى بالوصول (جدار الحماية)

على Windows Server، افتح «موجّه الأوامر» كمسؤول ونفّذ:

netsh advfirewall firewall add rule name="Contracts System" dir=in action=allow protocol=TCP localport=8080

لتغيير رقم المنفذ: Start-Windows.bat --port 80 أو python server.py --port 80.

3. إضافة الموظفين

  1. ادخل بحساب المدير، ثم افتح «الإعدادات والاستيراد».
  2. في قسم «المستخدمون والصلاحيات»: اكتب الاسم الكامل، واسم المستخدم (بالإنجليزية، مثل ahmed.ali)، واختر الصلاحية، واضغط «توليد كلمة مرور» ثم «حفظ المستخدم».
  3. أبلغ الموظف بالرابط واسم المستخدم وكلمة المرور. يستطيع تغيير كلمة المرور بنفسه من «حسابي».
الصلاحيةماذا تستطيع
مدير النظامكل شيء، بما فيه إدارة المستخدمين وسجل النشاط والنسخ الاحتياطي.
محررإضافة العقود والمنشآت والتمديدات والمراسلات وتعديلها وحذفها، ورفع ملفات PDF، والاستيراد من Excel.
مشاهدالاطلاع والبحث والتصفية وتصدير Excel فقط، دون أي تعديل.

كل عملية إضافة أو تعديل أو حذف تُسجَّل في «سجل النشاط» باسم المستخدم ووقتها.

4. التشغيل التلقائي مع الخادم

على Windows

  1. افتح Task Scheduler (برنامج جدولة المهام) ← Create Task.
  2. تبويب General: اختر Run whether user is logged on or not.
  3. تبويب Triggers: At startup.
  4. تبويب Actions: البرنامج python، والوسائط server.py، وStart in هو مجلد المنظومة (مثل C:\ContractsSystem).
  5. تبويب Settings: ألغِ خيار «Stop the task if it runs longer than».

على Linux

استخدم الملف المرفق contracts-system.service (عدّل المسار واسم المستخدم داخله):

sudo cp contracts-system.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now contracts-system

5. النسخ الاحتياطي

  • كل البيانات في المجلد data: قاعدة البيانات system.db وملفات PDF المرفوعة في data/files.
  • تحفظ المنظومة نسخة احتياطية تلقائية يوميًا في data/backups، وتحتفظ بآخر 30 يومًا.
  • يستطيع المدير تنزيل نسخة فورية من «الإعدادات ← النسخ الاحتياطي».
  • يُنصح بشدة بنسخ مجلد data كاملًا بشكل دوري إلى جهاز آخر أو وحدة تخزين خارجية.

للاستعادة: أوقف المنظومة، ثم ضع ملف النسخة الاحتياطية مكان data/system.db بنفس الاسم، ثم شغّلها من جديد.

6. التحديث إلى نسخة أحدث

أوقف المنظومة، ثم استبدل كل الملفات ما عدا مجلد data، ثم شغّلها. تبقى البيانات والمستخدمون كما هم.

7. نسيان كلمة مرور المدير

python server.py --reset-admin

تظهر كلمة مرور جديدة للمستخدم admin.

8. ملاحظات الأمان

  • المنظومة مصممة للعمل داخل الشبكة الداخلية فقط. لا تفتح منفذها على الإنترنت مباشرة.
  • إذا احتجتم الوصول من خارج المبنى، فليكن عبر VPN المؤسسة، أو خلف خادم وسيط (مثل IIS أو Nginx) بشهادة HTTPS.
  • كلمات المرور محفوظة مشفّرة (PBKDF2)، وتنتهي جلسة الدخول بعد 12 ساعة.
  • احذف حسابات الموظفين الذين يغادرون العمل فورًا من قسم المستخدمين.
